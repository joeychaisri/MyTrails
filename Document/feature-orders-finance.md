# หน้า Orders (Finance) — คู่มือการใช้งานสำหรับบัญชี

**เข้าถึงได้จาก:** เมนู "Orders (Finance)" ภายในแต่ละ event  
**หน้าที่หลัก:** ดูรายการสมัครทั้งหมด อัปเดตสถานะการเงิน และ export ข้อมูลสำหรับทำบัญชี

---

## ภาพรวมหน้าจอ

เมื่อเข้ามาจะเห็น 4 ตัวเลขสรุปด้านบนสุดก่อนเสมอ:

| ช่อง | ความหมาย |
|------|----------|
| **Total Collected** | ยอดรวมที่เก็บได้จริง (นับเฉพาะ order ที่ชำระแล้ว ไม่นับ refund) |
| **Pending Review** | จำนวน order ที่ยังรอตรวจสอบ |
| **Issues** | จำนวน order ที่มีปัญหา เช่น ยอดเงินไม่ตรง |
| **Refunded** | ยอดรวมที่คืนเงินไปแล้ว |

> ตัวเลขทั้ง 4 นี้แสดงยอดรวมของ **ทุก order ในงาน** เสมอ ไม่เปลี่ยนแปลงตามตัวกรองที่เลือก

---

## การกรองและค้นหา

### กรองตามช่วงเวลา
เลือกได้ว่าจะดู order ของช่วงไหน: วันนี้ / 7 วันล่าสุด / เดือนนี้ / หรือกำหนดเองตามช่วงวันที่ต้องการ

### กรองตามประเภท
กรองร่วมกันได้ 3 แบบ:
- **ช่องทางชำระเงิน** — Stripe / Cash / VIP / Sponsor
- **ระยะวิ่ง** — เช่น 100K Ultra / 50K Trail / 25K Fun Run
- **ประเภท Ticket** — เช่น Early Bird / Regular / VIP / Sponsor

เมื่อเลือกกรองอะไรไปแล้ว จะมีปุ่ม **"Clear filters"** ให้กดรีเซ็ตกลับทั้งหมดได้ในคลิกเดียว

### Tab แบ่งกลุ่ม order
| Tab | แสดง order กลุ่มไหน |
|-----|---------------------|
| **All** | ทุก order |
| **Completed** | order ที่ออกเอกสารแล้ว (ใบรับมัดจำ / TRC / CrN) |
| **Pending** | order ที่รอดำเนินการ |
| **Issues** | order ที่มีปัญหาต้องแก้ไข |
| **Refunds** | order ที่อยู่ในกระบวนการคืนเงิน |
| **Special** | order ประเภทพิเศษ เช่น VIP / Sponsor / WNS |

### ค้นหา
พิมพ์ชื่อผู้สมัคร, อีเมล หรือ Order ID เพื่อค้นหาได้โดยตรง

---

## รายการ Order ในตาราง

แต่ละ order แสดงข้อมูล: Order ID / ชื่อ-อีเมลผู้ซื้อ / ระยะวิ่ง / ช่องทางชำระ / ยอดเงิน / สถานะ / วันเวลา / โน้ต

### สถานะ (Status) ทั้งหมด

**กลุ่ม Stripe (ชำระออนไลน์)**

| สถานะ | ความหมาย |
|-------|----------|
| Submitted | ยื่นใบสมัครแล้ว รอตรวจสอบ |
| Complete Stripe · รอใบรับมัดจำ | ชำระผ่าน Stripe แล้ว รอออกใบรับมัดจำ |
| Complete · รอใบรับมัดจำ | ชำระแล้ว รอออกใบรับมัดจำ |
| Complete · เปิดใบรับมัดจำแล้ว | ออกใบรับมัดจำให้ลูกค้าแล้ว |
| Complete Stripe · รอออก TRC | ชำระผ่าน Stripe แล้ว รอออกใบกำกับภาษี |
| Complete · รอออก TRC | ชำระแล้ว รอออกใบกำกับภาษี |
| Complete · ออก TRC แล้ว | ออกใบกำกับภาษีให้ลูกค้าแล้ว |
| Complete · รอออก CrN | รอออก Credit Note |
| Complete · ออก CrN แล้ว | ออก Credit Note แล้ว |

**กลุ่มเปลี่ยนชื่อ**

| สถานะ | ความหมาย |
|-------|----------|
| Complete เปลี่ยนชื่อ · ใบรับมัดจำแล้ว (คนใหม่) | เปลี่ยนชื่อผู้สมัครแล้ว — สถานะฝั่งคนใหม่ |
| เปลี่ยนชื่อ · เปิดใบรับมัดจำแล้ว (คนเก่า) | เปลี่ยนชื่อผู้สมัครแล้ว — สถานะฝั่งคนเก่า |

**กลุ่ม Cash (ชำระเงินสด)**

| สถานะ | ความหมาย |
|-------|----------|
| รอตรวจ · เงินสด | ลูกค้าแจ้งชำระเงินสดแล้ว รอทีมตรวจยืนยัน |
| มีปัญหา · เงินสด | ตรวจสอบแล้วพบปัญหา เช่น ยอดเงินไม่ตรง |

**กลุ่ม Refund (คืนเงิน)**

| สถานะ | ความหมาย |
|-------|----------|
| รอคืนเงิน | อยู่ระหว่างดำเนินการคืนเงิน |
| มีปัญหา · คืนเงิน | การคืนเงินติดปัญหา |
| Refunded | คืนเงินเรียบร้อยแล้ว |
| Refunded · เปิดใบรับมัดจำแล้ว | คืนเงินแล้ว และออกใบรับมัดจำไปแล้วก่อนหน้า |

**กลุ่มพิเศษ**

| สถานะ | ความหมาย |
|-------|----------|
| Complete VIP | order ประเภท VIP เสร็จสมบูรณ์ |
| Complete Sponsor | order ประเภท Sponsor (ไม่เสียค่าสมัคร) |
| Complete Will not Start | สมัครและชำระแล้ว แต่แจ้งว่าจะไม่มาแข่ง (WNS) |
| Complete WNS · เปิดใบรับมัดจำแล้ว | WNS และออกใบรับมัดจำแล้ว |

**กลุ่มรอแก้ไข**

| สถานะ | ความหมาย |
|-------|----------|
| แก้ไข TRC | ใบกำกับภาษีออกไปแล้วแต่ต้องแก้ไข |

---

## สิ่งที่แก้ไขได้โดยตรงในหน้านี้

### 1. เปลี่ยนสถานะ
คลิก dropdown ที่คอลัมน์ Status ของ order แล้วเลือกสถานะใหม่ได้ทันที

### 2. เพิ่ม/แก้ไข Note
คลิกช่อง Note ของ order แล้วพิมพ์ได้เลย ใช้สำหรับบันทึกข้อมูลภายในทีม เช่น "Cancelled due to injury" หรือ "Amount mismatch"

---

## การดูรายละเอียด Order

**คลิกที่แถว order** เพื่อเปิดหน้าต่างรายละเอียด ซึ่งแสดง:
- ชื่อ, อีเมล, เบอร์โทรของผู้ซื้อ
- ระยะวิ่ง, ประเภท Ticket, ไซส์เสื้อ, หมายเลข BIB (ถ้ามีแล้ว)
- ช่องทางชำระเงินและยอดเงิน
- แก้ไขสถานะและ Note ได้ในหน้าต่างเดียวกัน
- ปุ่ม Refund / เปลี่ยนระยะวิ่ง / Issue Tax Invoice

---

## การทำรายการหลายออเดอร์พร้อมกัน (Bulk)

1. ติ๊ก checkbox หน้า order ที่ต้องการ (หรือติ๊กที่หัวตารางเพื่อเลือกทั้งหมดที่กำลังแสดงอยู่)
2. จะมีแถบโผล่ที่ด้านล่างจอ
3. เลือกสถานะที่ต้องการเปลี่ยน ระบบจะอัปเดตทุก order ที่เลือกพร้อมกัน

---

## Export ข้อมูล

ปุ่ม **Export** มุมขวาบน จะดาวน์โหลดไฟล์ `.csv` ของ order ที่กำลังแสดงอยู่ (ตาม filter ที่เลือก)

ไฟล์มีคอลัมน์: Order ID / ชื่อ / อีเมล / ระยะวิ่ง / ประเภท Ticket / ช่องทางชำระ / ยอดเงิน (บาท) / สถานะ / วันเวลา / Note

> ไฟล์รองรับภาษาไทยใน Excel โดยตรง

## คำย่อที่ใช้ในระบบ

| คำย่อ | ความหมาย |
|-------|----------|
| **TRC** | Tax Receipt — ใบกำกับภาษี |
| **CrN** | Credit Note |
| **WNS** | Will Not Start — สมัครแล้วแต่ไม่มาแข่ง |
| **DNS** | Did Not Start — มาแต่ไม่ได้ออกสตาร์ท (มักเขียนในช่อง Note) |
