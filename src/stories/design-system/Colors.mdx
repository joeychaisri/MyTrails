# Colors

All colors are HSL CSS custom properties defined in `src/index.css`. Swatches below
render from the live variables, so they can never drift from the code. Each token
lists both dialects: the shadcn name (Organizer/Admin, via Tailwind) and the `--mt-*`
alias (Runner side).
