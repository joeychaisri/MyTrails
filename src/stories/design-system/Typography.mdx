# Typography

One family stack for the whole product, loaded via `@fontsource` in `src/index.css`:

```
Inter, Noto Sans Thai, system-ui, sans-serif     (--mt-font-sans / Tailwind font-sans)
```

**Inter** carries Latin text; **Noto Sans Thai** transparently covers Thai glyphs in
the same runs — never switch families manually for Thai. Loaded weights: **400 / 500 /
600 / 700** (regular, medium, semibold, bold). Don't use other weights; they'd render
as faux-bold.

## Runner-side helpers

The Runner pages define a few typographic utility classes in `index.css` — reuse them
instead of re-declaring the same recipe:

- `.mt-eyebrow` — `600 12px`, muted, uppercase-tracking eyebrow above section titles.

## Rules

- Thai copy: keep the year **Gregorian** when formatting dates (`Intl.DateTimeFormat`
  with `th-TH` flips to the Buddhist era — append the year number yourself).
- Don't introduce new sizes off the scale above without asking the UX owner.
