# Surfaces — radius, shadows, gradients

How raised things look. All values live in `src/index.css` / `tailwind.config.ts`.

## Border radius

Base token `--radius: 0.75rem` (`--mt-radius`), stepped down by Tailwind config:

Cards use `rounded-xl` (16px); badges and pills use `rounded-full`.
