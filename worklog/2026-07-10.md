# Worklog — 2026-07-10

ปรับ flow ตาม feedback จาก PO ทั้ง 9 ข้อ (ทำเป็น 4 เฟส แต่ละเฟสตรวจ type/test/build ผ่านก่อนไปต่อ)

## 1. Lifecycle ใหม่ + ตัดขั้นตอนที่ไม่ใช้ (ข้อ 7, 8)

### เปลี่ยน
- **สถานะงานเหลือ 5 แบบ** (จากเดิม 7): ร่าง → รอตรวจสอบ → (ตีกลับ) / อนุมัติแล้ว → **ตั้งเวลา (Scheduled)** → เผยแพร่
- **ตัด flow "ขอยกเลิกงาน" ทิ้งทั้งหมด** — organizer ยกเลิกงานที่เผยแพร่แล้วไม่ได้ (ตามที่ PO ขอ) เหลือแค่ Admin กด "Force Unpublish" กรณีฉุกเฉิน
- Admin ไม่ต้องกดปุ่ม Publish เองแล้ว (ดูข้อ 3)

## 2. Publish date — organizer เลือกเวลาเผยแพร่เอง (ข้อ 5, 6, 7)

### เปลี่ยน
- เพิ่ม **หน้า "Publishing" ใน Wizard** — organizer เลือกได้ว่า **เผยแพร่ทันทีที่อนุมัติ (ASAP)** หรือ **กำหนดวันเวลาเอง**
- **หลัง Admin อนุมัติ:** ถ้า ASAP → งานขึ้นเลย, ถ้ากำหนดเวลา → เป็น "Scheduled" แล้ว**ขึ้นเองอัตโนมัติเมื่อถึงเวลา**
- Admin เห็นวันเวลาเผยแพร่ในหน้ารีวิวงานด้วย

## 3. แก้อะไรก็ต้องอนุมัติใหม่ (ข้อ 9)

### เปลี่ยน
- งานที่อนุมัติแล้ว (Scheduled/Live) ถ้า organizer แก้ → **กลับไปเข้าคิวรอตรวจสอบใหม่ + หลุดจากหน้าสาธารณะ**จนกว่าจะอนุมัติอีกครั้ง
- มี**คำเตือน**ตอน organizer กดแก้งานที่เผยแพร่แล้ว

## 4. ระบบ Tier แบบจัดการเองได้ (ข้อ 2)

### เปลี่ยน
- Tier ของ organizer กลายเป็น **ข้อมูลที่ Admin จัดการเองได้** (เพิ่ม/แก้ชื่อ/แก้ค่าคอม/ลบ) ในหน้า Settings
- ลบ tier ที่มี organizer ใช้อยู่ไม่ได้ (ต้องย้ายก่อน)
- ตอนสร้างบัญชี organizer เลือก tier จากรายการจริง

## 5. Commission 2 ส่วน + Admin ปรับได้ (ข้อ 3)

### เปลี่ยน
- ค่าคอมแบ่งเป็น 2 ส่วน:
  1. **Event commission — คิดตามจำนวนผู้สมัคร:** ต่ำกว่า 300 คน = เหมา 1,000฿ / 300–999 คน = 8% / ตั้งแต่ 1,000 คน = 6% (งานใหญ่ได้เรตดีกว่า)
  2. **Tier commission** — ตาม tier ของบัญชี
- **Wizard มีหน้าแจ้งค่าคอม** ให้ organizer เห็นก่อนส่งว่าจะเสียเท่าไหร่ (แยก 2 ส่วน + รวม)
- **Admin ปรับ event commission ของงานนั้นได้เอง**ตอนรีวิว
- ตอนจ่ายเงินจริง (payout) คิดจาก**ยอดสมัครจริง**, ตอนแจ้งใน wizard เป็นประมาณการจาก capacity

## 6. Ticket ผูกเวลา (ข้อ 4)

### เปลี่ยน
- price tier แต่ละอันกำหนด **ช่วงเวลาขายได้** (Early Bird หมดเวลา → Normal ราคาแพงกว่าเริ่มต่อ)
- Admin เห็นช่วงเวลาของแต่ละ tier ในหน้ารีวิว
- (ฝั่งหน้าเว็บสาธารณะของนักวิ่ง — logic เลือก tier ตามเวลา เก็บไว้ทำรอบถัดไปตามที่ตกลง)

## 7. สุ่มรหัสผ่านแข็งแรงตอนสร้างบัญชี organizer (ข้อ 1)

### เปลี่ยน
- เพิ่มปุ่ม **"Generate"** สุ่มรหัสผ่านแข็งแรง (มีตัวใหญ่/เล็ก/เลข/สัญลักษณ์) ให้ Admin ก๊อปไปส่ง organizer
